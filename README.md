# 📝 Graphical To-Do List

A clean and interactive **To-Do List web application** built using **HTML, CSS, and JavaScript**. The project focuses on creating a visually appealing frontend interface while providing a simple and practical task-management experience.

## ✨ Features

* ➕ Add new tasks
* ✅ Mark tasks as completed
* 🗑️ Delete tasks
* 🎨 Graphical and responsive user interface
* ⚡ Fast and lightweight
* 🖥️ Works directly in the browser
* 📱 Responsive design for different screen sizes

## 🛠️ Technologies Used

* **HTML5** – Structure of the application
* **CSS3** – Styling, layout, animations, and visual design
* **JavaScript** – Task management and user interactions

graphical-todo-list/

## ⚙️ How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/soumya751/graphical-todo-list.git
```

2. Open the project folder:

```bash
cd graphical-todo-list
```

3. Open `index.html` in your browser.

That's it! No additional installation or dependencies are required.
